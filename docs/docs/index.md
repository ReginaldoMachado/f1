# F1 Explorer

O F1 Explorer e um dashboard Streamlit para explorar dados historicos da
[OpenF1](https://openf1.org/docs/), sem autenticacao para temporadas passadas.

## Funcionalidades

- Selecao de temporada, Grande Premio e sessao.
- Ranking das dez voltas validas mais rapidas, com piloto e equipe.
- Resumo de voltas validas, melhor tempo e media.
- Validacao dos payloads e tratamento de falhas de rede.

Dados em tempo real exigem uma assinatura OpenF1 e nao fazem parte deste projeto.
